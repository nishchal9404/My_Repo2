# Birthday Gift SPA

Welcome to the Birthday Gift SPA project! This is a highly interactive, single-page web application designed to present a digital birthday gift in a cozy and romantic aesthetic. The application features smooth transitions, custom state logic, and a beautiful crimson/dark pink theme.

## Features

- **Passcode Lock Screen**: A secure entry point where users can input a passcode to access the gift presentation.
- **Animated Celebration Greeting**: A cheerful greeting page with playful animations to celebrate the birthday.
- **Gift Hub**: A selection screen showcasing various interactive gifts, each leading to unique experiences.
- **Interactive Views**: Engage with different gifts through fun interactions, including blowing out candles, viewing a scrapbook, and reading a love letter.

## Technologies Used

- **React**: For building the user interface and managing application state.
- **Tailwind CSS**: For rapid and responsive UI design.
- **Vanilla JavaScript**: For handling custom logic and interactions.
- **Vite**: As the build tool for fast development and production builds.

## Setup Instructions

1. **Clone the Repository**:
   ```bash
   git clone <repository-url>
   cd birthday-gift-spa
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Run the Application**:
   ```bash
   npm run dev
   ```

4. **Open in Browser**: Navigate to `http://localhost:3000` (or the specified port) to view the application.

## Customization

- Modify the passcode in `src/data/content.js` to change the entry code.
- Update the background music and animations as needed for a personalized touch.
